# Holly Hearn — Portfolio

A static portfolio prepared for GitHub Pages, with a project grid and two project pages. Open `index.html` locally or serve this folder with a static web server.

## Publishing

Create a repository named `hollyhearn.github.io`, upload these files to its main branch, then select Settings → Pages → Deploy from a branch → main / root. The intended address is https://hollyhearn.github.io/ (publication is not yet configured).

## Images and typography

Current images were extracted from Holly's supplied Spring 2026 portfolio PDF for design review. Replace with original high-resolution exports before the final launch. Text is adapted from that PDF. Confirm project captions and collaboration credits before publishing.

The stylesheet prefers locally installed Avenir and Avenir Next, then system sans-serif fonts. No commercial font files are bundled. A licensed webfont or approved alternative can be added for identical typography across devices.
